# Journal des versions

## 1.0.0

- Connecteur MCP `odoo` : connexion, modèles, champs, boutons, recherche, lecture, regroupement,
  écriture en deux temps (préparer puis appliquer) : créer, modifier, action, supprimer,
  dans les droits du compte Odoo.
- Skill `odoo-production-qualite` : méthode, modèles et recettes production et qualité.
- `setup.ps1` : installation, diagnostic, essai à blanc, saisie de la clé API dans une
  fenêtre masquée ; `CLAUDE.md` pour une installation entièrement pilotée par Claude.
- Connu : le connecteur parle à Odoo par `/jsonrpc`, annoncé obsolète à partir d'Odoo 20.
